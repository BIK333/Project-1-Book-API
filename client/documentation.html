Book API Documentation

Information about the available API endpoints

About the API

The Book API allows users to view, search, add, and update information about books. Book data is stored in memory while the server is running.

Return to Book Finder

GET /api/books

Relative URL: /api/books

Supported Methods: GET, HEAD

Returns all of the books currently stored by the server.

Return Format: JSON containing an array of book objects.

Successful Status: 200 OK

Example Request

GET /api/books

GET /api/titles

Relative URL: /api/titles

Supported Methods: GET, HEAD

Returns the titles of all books currently stored by the server.

Return Format: JSON containing an array of book titles.

Successful Status: 200 OK

Example Request

GET /api/titles

GET /api/authors

Relative URL: /api/authors

Supported Methods: GET, HEAD

Returns a list of authors from the current book data.

Return Format: JSON containing an array of author names.

Successful Status: 200 OK

Example Request

GET /api/authors

GET /api/search

Relative URL: /api/search

Supported Methods: GET, HEAD

Searches the book data using genre or language query parameters. The filtering is handled by the API.

Query Parameters

genre — String — Optional
Filters the results based on book genre.

language — String — Optional
Filters the results based on book language.

Return Format: JSON containing an array of matching book objects.

Successful Status: 200 OK

Genre Example

GET /api/search?genre=Fairy

Language Example

GET /api/search?language=English

POST /api/addBook

Relative URL: /api/addBook

Supported Method: POST

Adds a new book to the in-memory book data.

This endpoint accepts both JSON and application/x-www-form-urlencoded request bodies.

Body Parameters

title — String — Required

author — String — Required

country — String — Optional

language — String — Optional

pages — Number — Optional

year — Number — Optional

Return Format

A successful request returns JSON containing a success message and the newly created book.

Possible Status Codes

201 Created: The book was successfully added.

400 Bad Request: Required information is missing or a book with the same title already exists.

Example JSON Body

{"title":"Example Book","author":"Example Author","language":"English","pages":250,"year":2026}

POST /api/updateBook

Relative URL: /api/updateBook

Supported Method: POST

Updates an existing book. The title is used to find the book that should be updated.

This endpoint accepts both JSON and application/x-www-form-urlencoded request bodies.

Body Parameters

title — String — Required

author — String — Optional

country — String — Optional

language — String — Optional

pages — Number — Optional

year — Number — Optional

Return Format

A successful update returns a 204 No Content response. Error responses return JSON containing an error message.

Possible Status Codes

204 No Content: The book was successfully updated.

400 Bad Request: A book title was not provided.

404 Not Found: A book with the provided title could not be found.

Example JSON Body

{"title":"Example Book","author":"Updated Author"}

Other Errors

Requests made to an endpoint that does not exist return 404 Not Found.

Invalid request bodies or unsupported Content-Types return 400 Bad Request.
