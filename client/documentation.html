Book API Documentation

Information about the available API endpoints

About the API

The Book API allows users to view, search, add, and update information about books. Book data is stored in memory while the server is running.

Return to Book Finder

GET /api/books

Methods: GET, HEAD

Returns all of the books currently stored by the server.

Successful Status: 200 OK

Example Request

GET /api/books

GET /api/titles

Methods: GET, HEAD

Returns the titles of all books.

Successful Status: 200 OK

Example Request

GET /api/titles

GET /api/authors

Methods: GET, HEAD

Returns a list of authors from the book data.

Successful Status: 200 OK

Example Request

GET /api/authors

GET /api/search

Methods: GET, HEAD

Searches the book data using a genre or language query parameter.

Genre Example

GET /api/search?genre=Fairy

Language Example

GET /api/search?language=English

Successful Status: 200 OK

POST /api/addBook

Method: POST

Adds a new book to the in-memory book data.

The title and author fields are required. Other book information can also be included.

This endpoint accepts JSON and application/x-www-form-urlencoded request bodies.

Possible Status Codes

201 Created: The book was successfully added.

400 Bad Request: Required information is missing or a book with the same title already exists.

POST /api/updateBook

Method: POST

Updates an existing book. The title is used to find the book that should be updated.

This endpoint accepts JSON and application/x-www-form-urlencoded request bodies.

Possible Status Codes

204 No Content: The book was successfully updated.

400 Bad Request: A book title was not provided.

404 Not Found: A book with the provided title could not be found.

Other Errors

Requests made to an endpoint that does not exist return 404 Not Found.

Invalid request bodies or unsupported Content-Types return 400 Bad Request.
